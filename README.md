# OSM Game

Мобильная стратегия: энергетика, промышленность и логистика на реальной карте Украины
(данные © участники OpenStreetMap).

## Как получить APK
Каждый пуш в `main` собирает APK в GitHub Actions. Готовый файл — во вкладке
**Releases** (или Actions → последний запуск → Artifacts).

## Устройство
- `assets/config/game.json` — все здания, ресурсы, напряжения, месторождения. Новое здание = новая запись.
- `tools/fetch_osm.py` — скачивает данные OSM при сборке (области, реки, города, ЛЭП ≥220 кВ, подстанции, станции).
- `assets/data/` — запасные данные, если OSM не скачался.
- `lib/sim/` — симуляция (энергосеть, производство, поезда), не зависит от интерфейса.
- `lib/ui/` — интерфейс (карта, панели).

`ci/debug.keystore` — отладочный ключ подписи, чтобы новые версии ставились поверх старых.
